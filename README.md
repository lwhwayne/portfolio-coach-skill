# Portfolio Coach｜作品集教练

一个面向 UX、交互、体验、产品和 UI 设计师的 AI Skill。它会结合使用者自己的目标岗位与项目材料，帮助筛选项目、梳理设计判断，并给出具体的逐页表达和排版建议。

它不会要求所有作品集套用同一种结构，也不会根据缺失信息编造访谈、备选方案、个人贡献或成果数据。

## 能做什么

- 判断哪些项目适合作为主案例、辅助案例或附录
- 检查不同项目证明的能力是否重复或互补
- 梳理复杂项目的核心矛盾、约束与设计判断
- 区分前后优化、真实候选方案和落地妥协
- 指导流程、规则、状态、异常和多角色协作的表达
- 根据内容类型给出逐页排版建议
- 检查成果指标的基线、样本、归因和结论强度
- 根据现有材料准备面试追问
- 在用户需要时，一次只问一个问题逐步补充信息

## 安装

### ChatGPT / Codex

1. 下载本仓库，或下载仓库 ZIP。
2. 将 `portfolio-coach` 文件夹作为 Skill 导入支持 Skills 的 ChatGPT 或 Codex。
3. 安装后可以直接上传作品集并提问，也可以显式调用：

```text
使用 $portfolio-coach 分析我上传的设计作品集，并给出项目选择、叙事与逐页排版建议。
```

### 其他 AI 工具

如果工具支持项目指令、Agent Skill 或知识文件，可将 `portfolio-coach/SKILL.md` 作为核心指令，并同时提供 `portfolio-coach/references/` 下的参考文件。不同产品的自动触发和文件读取方式不同，迁移后需要用真实案例测试。

## 使用示例

```text
我想投 3 年经验的交互设计师。这是我的完整作品集，请先判断项目组合是否合理，再告诉我最该修改的三处。
```

```text
这是作品集中的一个项目。请判断它最适合证明什么能力，并帮我重新安排项目叙事。
```

```text
这是其中一页截图。请只根据这一页判断内容和排版问题，不要假设没有提供的项目背景。
```

## 输出方式

Skill 会根据问题规模选择需要的输出，而不是每次生成完整长报告。常见结果包括：

- 总体判断与最高优先级行动
- 项目选择和能力组合
- 单个项目的叙事主线
- 方案取舍与证据缺口
- 逐页修改清单
- 面试追问和待核实信息

## 隐私与事实边界

仓库不包含作者原始作品集、项目截图、公司内部材料或个人履历。使用时请自行处理敏感信息。Skill 会区分已有事实、分析建议和待补信息，但最终仍应由作品集作者核对项目事实与数据口径。
